## 成卡处理

全批使用希尔瓦娜斯 v7 的默认装饰：顶部铭牌与称号、中下绶带、三属性圆章、底部双徽章。逐卡调整脸部及场景金线禁区，均关闭额外月环拟合。泰兰德裁底 0.12、玛维 0.16，使脸部/头盔避开固定标题区；其余新卡裁底为 0。裁剪同步用于原画与深度，原文件不被裁切，泰兰德、玛维的成卡会裁去部分原图下方。

新卡全部使用 2 逻辑像素的深度平滑。瓦里安、安度因、乌瑟尔、图拉扬、凯恩、贝恩和凯尔萨斯另设置非金属区域，避免夕阳、天空、毛皮、木材和石地因暖色被误判成金属。该配置只改变底图粗糙度，后续金脊与边框仍按原管线叠加；shader 和详情显示尺寸未变。

图拉扬第一次深度输出为 1023×1537，与原画尺寸不符，已隔离并重新生成精确匹配的版本。拒绝文件保留在 production/wow-imagegen 中，不被运行资产引用。

## 复现

在项目根启动 `node server.mjs --host 127.0.0.1 --port 7129`，打开 `http://127.0.0.1:7129/wow.html`。

1. `python3 production/build-wow-runtime.py [hero-id ...]` 编码原生配对母版。
2. 浏览器打开该工作区站点；`production/bake-wow-thumbs.cjs` 默认处理全部 23 张 ImageGen 卡，站点 URL 可用 `?ids=id1,id2` 限定批次。逐卡审核通过才导出缩略图，失败保留 QC 数据。
3. `python3 production/finalize-wow-manifest.py` 核对原图/编码/配对尺寸/成卡门槛，再记录最新缩略图、逐卡参数与校验哈希。
4. 执行 `test/verify-wow-materials.cjs`、`test/verify-wow-browser.cjs`，再运行 `npm run check` 与 `npm run build:pages`。浏览器脚本由 `playwright-cli run-code --filename=...` 运行。
5. 结束临时服务。改变原画、深度、字体、金线或装饰后须重新烘焙受影响卡片并刷新清单。
