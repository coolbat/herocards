# Atlas geography sources

`map-projected.svg` is generated by `npm run build:atlas` from the local files in
`assets/atlas/sources/`.

- Dataset: Natural Earth 1:110m land, lakes, and river centerlines
- Source: https://github.com/nvkelso/natural-earth-vector
- License: public domain
- Projection: `web-mercator-eurasia-indian-ocean-v1`, declared in
  `js/atlas-data.js`

The generated SVG is the runtime asset. The GeoJSON files are build inputs and
the original painterly `map.webp` is retained only for the calibration tool and
visual reference.
