## 任务：生成两种备选风格的李白卡面源图

同一构图、同一人物、不同画风，用于和工笔重彩版做 A/B/C 对比：

**风格A · 水墨淡彩**（保存为 `assets/portraits/full/libai-shuimo-4k.png`）：
水墨淡彩国画，留白多、墨色晕染、淡彩点染，气质清雅文人。

**风格B · 敦煌壁画风**（保存为 `assets/portraits/full/libai-dunhuang-4k.png`）：
敦煌壁画质感，石绿/赭石/土红/金箔配色，墙面斑驳做旧肌理，飘带如飞天。

**两种风格都必须遵守的管线硬约束**（违反任何一条图就废了）：
1. 李白全身像、站姿、占画面 50–60%，举杯邀月动作，头后一轮巨大金黄满月作为唯一光晕锚点——整个天空只有这一轮明月，没有其他月亮/光晕圆盘/第二个发光天体
2. 场景=长安月夜酒肆庭院，中景具体物件（酒肆楼阁、红灯笼、牡丹、石桌酒坛），前景石阑干+水面月影，远景城墙佛塔
3. 头顶与脚下留白充裕（9:16 要居中裁 2:3）
4. 人物最锐利细节最丰富，远景空气感更柔和，纵深分层明确
5. 无文字、无印章、无边框、无水印、无签名、无密集碎线、无整片星空

## 执行方式

```bash
export PATH="$HOME/.local/bin:$PATH"
dreamina text2image --model_version=4.7 --ratio=9:16 --resolution_type=4k --generate_num=1 --prompt="<你的提示词>"
# 拿到 submit_id 后轮询下载（不加 --poll，query_result 自带下载）：
dreamina query_result --submit_id=<id> --download_dir=<目录>
# 失败（final generation failed）就退避 10–60s 原样重试
```

- 提示词全部用中文，参照上面约束自己组织（结构参考：画风定义 → 人物 → 月亮锚点 → 场景中景/前景/远景 → 色调 → 质量约束）
- 每张图下载后用 PIL 居中裁 2:3，分别存 `libai-shuimo-full.png` 和 `libai-dunhuang-full.png`，并目检确认构图合规（全身、单月亮、无水印）
- 如果第一次出图构图/风格不对，就调整提示词重来，每种风格最多试 3 次，选最好的一张
- **不要改任何 js/css/html 文件**，只生成图片资产
- 完成后汇报：两张图的最终路径、各自用的提示词全文、尝试了几次、对两种风格与烫金描金管线契合度的判断（金线层是从画面主轮廓提取的——水墨的留白和敦煌的斑驳肌理会不会产生碎线，给个大方向判断即可）
