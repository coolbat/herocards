**铁律（违反即废，重抽）**：
1. **光晕锚点唯一**——即梦容易出双月/双日，提示词里反复强调「整个画面只有这一轮」，出图目检发现第二个发光体直接重抽
2. 人物全身、站姿、占画面 50–60%，头顶脚下留白充裕
3. 场景物件必须具体（不许「一些建筑」「若干装饰」这种空泛词）
4. 旗帜、书卷、册页上一律无字（提示词里写明「无字战旗」「无字书卷」）
5. 每张最多试 3 次，选最好的一张；final generation failed 退避 10–60s 原样重试

## 执行命令

```bash
export PATH="$HOME/.local/bin:$PATH"
# 源图（9:16 4k，每次 2 额度）：
dreamina text2image --model_version=4.7 --ratio=9:16 --resolution_type=4k --generate_num=1 --prompt="<提示词>"
dreamina query_result --submit_id=<id> --download_dir=<目录>   # query_result 无 --poll 旗标，自带下载
# 高度图（i2i 2:3 2k，参考图=裁剪后的卡面源图）：
dreamina image2image --model_version=4.7 --ratio=2:3 --resolution_type=2k --generate_num=1 \
  --image=<裁剪后源图路径> --prompt="<高度图提示词>"
```

源图下载后用 PIL 居中裁 2:3（3040×4560）。

1. 每张源图目检：全身？单光晕锚点？无字无水印？——不合格重抽（每张≤3 次）
2. 每张高度图目检：纯灰度？人物圆雕立体感？纹理压平？——不合格重抽（每张≤2 次）
3. 23 人的最终提示词全文存档到 `production/prompts-guofeng.json`（结构：`{ "<id>": { "sourcePrompt": "...", "heightPrompt": "...", "tries": n } }`）
4. 写报告 `production/mass-production-report.json`：每人 `{ id, fullArt, heightMap, ok, note, halo: { x, y, r } }`——halo 是光晕天体在**裁剪后 3040×4560 图**里的近似圆心/半径（物理像素，目估即可，后面管线要用它做月环引导，务必给）
5. 完成后在回复里汇总：成功 N/23、失败清单、每张试了几轮、额度消耗估算
