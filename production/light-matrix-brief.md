## 新提示词模板（掐丝珐琅 · 光源自由化 · 风格锁版，经康熙 4 轮试单验证）

```
掐丝珐琅景泰蓝工艺风格装饰画，中国传统工笔重彩与珐琅工艺结合，金丝掐出流畅均匀的轮廓线，珐琅釉彩平涂填色，色块边界清晰分明，平面装饰性构图，宝石蓝、松石绿、朱砂红、明黄，釉面莹润，华丽精致，边缘锐利，高解析度。禁止油画感、禁止写实照片感、禁止素描式明暗渐变、禁止柔焦虚化，人物面部用平面化细腻渲染而非写实光影。{人物}全身立像，站姿{气质}，占画面50-60%，{外貌服饰道具}。场景为{具体场景}。构图关键：{光源描述}，它是整个画面唯一的主光源和唯一亮色，{光照效果：用色块冷暖对比表现，不要写实光影}；{天空处置：夜景一律写"画面任何位置都不出现天空，上方只有廊檐/松枝/洞顶等遮挡物"}，绝对不要画月亮（一丁点月牙也不行），禁止太阳、圆盘、光环、头光，禁止第二个发光体。中景：{2-4个具体物件}。前景：{框景物}。远景：{远景}。掐丝金线粗细均匀流畅，不要密集碎线。头顶与脚下留白充裕。无文字、无印章、无边框、无水印、无签名。
```

**试单血泪（康熙 4 轮换来的，务必遵守）**：
1. **风格锁词必须前置**——「釉彩平涂、平面装饰、禁止油画写实」缺了就会跑偏成写实油画风（v1 事故）
2. **禁月不能靠否定词，要靠构图**——写「禁止月亮」模型照画不误（v2/v3/v4 连续三轮混进月亮）；夜景卡必须在提示词里写死「画面任何位置都不出现天空」，让月亮无处容身
3. **目检必查四角**——模型会偷画红色伪印章（v3 左下角事故）
4. **兜底手段**：若成图只有月亮/小瑕疵一处不合格，不必浪费重抽额度，用 PIL 补丁修复（从对称位置取无月天空圆形羽化贴回，脚本在 `qa/light-matrix/` 有样例）；两处以上违规才重抽

## 铁律（v2）

1. **主光源唯一**——按矩阵指定的光源，出图目检发现第二个发光体（多余灯笼/月亮/光环）直接重抽
2. **禁止头后正圆盘**——除非矩阵明确指定天体光源（本 16 人全部是器物/天光光源，一律不得出圆盘）
3. 人物全身、站姿、占画面 50–60%，头顶脚下留白充裕
4. 场景物件必须具体；旗帜、书卷、册页、典籍一律无字
5. 每张最多试 3 次选最优；生成失败退避 10–60s 重试
